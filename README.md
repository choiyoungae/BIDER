# Bider — 가장 가까운 경매장

> **더 가까이, 더 공정하게, 더 재미있게!**  
> 반경 5km 안 진짜 내 이웃과 즐기는 새로운 중고 경매 플랫폼

[👉 서비스 바로가기](https://bider.vercel.app/)

---

## 💡 기획 의도

중고거래는 많지만, **가까운 이웃끼리 믿고 거래하기엔 아쉬움**이 있었습니다.  
또한 흥정 과정에서 생기는 **번거로움과 불투명함**도 줄이고 싶었습니다.

> **“더 가까이, 더 공정하게, 더 재미있게!”**

그래서 **Bider**는 가장 가까운 이웃과,  
가장 스마트한 방식으로 거래하는 **새로운 중고 경매 경험**을 목표로 합니다.

---

## 🚀 Bider가 제공하는 가치

- 📍 **근거리 신뢰** — 반경 5km 제한으로 진짜 내 동네 거래
- ⚖️ **공정한 가격** — 입찰 시스템을 통한 합리적인 거래
- 📊 **투명한 정보** — 실시간 입찰 현황 확인
- 🗺️ **직관적 탐색** — 지도 중심 UI와 리스트 뷰 지원
- 🎮 **즐거운 경험** — 포인트, 제안하기, 시크릿 경매 등 재미 요소

---

## ✨ 핵심 기능

### 📍 위치 기반 거래

- 회원가입 후 **위치 등록** 필수
- 반경 **5km** 이내 상품만 조회 가능
- 가까운 이웃과만 거래 성사 → 신뢰도 높은 거래

### ⚖️ 입찰 경매 시스템

- 흥정 없이 **입찰 기반 최종가 결정**
- 누구나 동등한 조건에서 참여 가능

### 📊 실시간 입찰 현황판

- 새로운 입찰 발생 시 **즉시 반영**
- 입찰 시간·금액을 실시간 업데이트

### 🗺️ 지도 + 리스트 뷰

- **Google Maps API** 기반 지도 UI
- 마커로 주변 상품 직관적 확인
- 리스트 전환 + 다양한 필터/정렬 지원

### 🎮 포인트 시스템

- 서비스 활동으로 포인트 적립
- 시크릿 경매 열람, 제안하기 등에 사용
- 포인트 내역 조회/관리 가능

### 💡 제안하기

- **즉시 거래 제안** 기능
- 100포인트 사용 → 제안 등록
- 출품자 수락 시 즉시 낙찰 & 경매 종료

### 🕵️‍♂️ 시크릿 경매

- 입찰 현황 숨김 → 종료 시 낙찰
- 500포인트 사용 → 10분간 최고입찰가 열람 가능

### 💬 채팅 & 🔔 알림

- 낙찰자 ↔ 출품자 **1:1 채팅**
- 거래 시간/장소 조율
- 푸시 알림으로 입찰·제안·채팅 등 이벤트 전달
